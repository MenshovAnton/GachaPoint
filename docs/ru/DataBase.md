# База данных SQLite
Для отображения календаря используется база данных SQLite. В хранилище устройства распологается файл `gachamanager.db`, он содержит в себе таблицу `calendar`, которая в свою очередь хранит данные календаря (отметки, дни, оставшееся время подписки).

## Структура таблицы `calendar`
| **Наименование столбца** | **Комментарий**                                            | **Тип данных** | **Назначение**                                 |
|--------------------------|------------------------------------------------------------|----------------|------------------------------------------------|
| `id`                     | ID столбца. Динамическая нумерация.                        | `int`          | Идентификация.                                 |
| `day`                    | День месяца.                                               | `int`          | Значение, отображаемое в ячейке календаря.     |
| `dayyear`                | День относительно года.                                    | `int`          | Отсчет годов.                                  |
| `dayweek`                | День относительно недели.                                  | `int`          | Корректировка отображения недель на календаре. |
| `month`                  | Месяц.                                                     | `int`          | Наименование месяца для навигации.             |
| `year`                   | Год.                                                       | `int`          | Год для навигации.                             |
| `statusgenshin`          | Сататус отметки для Genshin Impact.                        | `int`          | Отметка сбора Благословления Полной Луны.      |
| `drgenshin`              | Количество оставшихся дней подписки для Genshin Impact.    | `int`          | Оставшиеся дни Благословления Полной Луны.     |
| `statushsr`              | Статус отметки для Honkai Star Rail.                       | `int`          | Отметка сбора награды Пропуска Экспресса.      |
| `drhsr`                  | Количество оставшихся дней подписки для Honkai Star Rail.  | `int`          | Оставшиеся дни Пропуска Экспресса.             |
| `statuszzz`              | Статус отметки для Zenless Zone Zero.                      | `int`          | Отметка сбора награды Интернот-подписки.       |
| `drzzz`                  | Количество оставшихся дней подписки для Zenless Zone Zero. | `int`          | Оставшиеся дни Интренот-подписки.              |

### Кодовые значения статусов отметки
- `0` - пропущено/нет подписки, 
- `1` - собрано, 
- `2` - пропущено (закончившаяся подписка), 
- `3` - собрано (закончившаяся подписка).

### Категории дней
- `day` - Отображаемое значение. Номер дня в месяце.
- `dayyear` - Техническое значение. Используется для отсчета годов при генерации и чтении/записи БД календаря.
- `dayweek` - Техническое значение. Используется для корректного отображение недель и дней относительно дней недели.
