# Класс Calendar
Отображения календаря и временное хранения состояния календаря при открытом приложении. Помещает в себя массив календаря `dateArray`, служащий временным хранением состояния БД относительно выбранного типа подписки (`subType` в классе `MainActivity`), массивы `dateViewArray` и `dateBackArray`, представляющие набор TextView и ImageView для отображения календаря соответственно.

## Объект Date
Массив `dateArray` хранит в себе объекты типа ``. Они представляют собой набор данных типа `int`, отражающих конкретное число календаря.

| **Поле**           | **Описание**                                                                                                     |
|--------------------|------------------------------------------------------------------------------------------------------------------|
| `id`               | Идентификатор, номер дня относительно года начиная с нуля                                                        |
| `dayOfMonth`       | День в месяце                                                                                                    |
| `dayOfYear`        | День, относительно года                                                                                          |
| `dayOfWeek`        | День, отностиельно недели                                                                                        |
| `year`             | Год                                                                                                              |
| `status`           | Састус отметки выбранной подписки (см. [База Данных -> Кодовые значения статусов отметки](/docs/ru/DataBase.md)) |
| `subDaysRemaining` | Количество оставшихся дней выбранной подписки                                                                    |
| `month`            | Месяц                                                                                                            |
