**GachaPoint** - ваш универсальный помощник по аниме гача RPG играм с открытым исходным кодом. Отслеживайте подписки на гемы, накопления и крутки. 

## Возможности (WIP)
- **Отслеживание подписок** - наглядная статистика по вашим подписками в виде календаря и счетчика гемов/круток
- **История круток** - сохраняйте историю ваших круток, следите за вашим прогрессом*
- **Менеджер накоплений** - следите за прогрессом ваших накоплений.
- **Ежедневные напоминания** - напомнит забрать награды в игре.
- **Работает автономно** - вся информация храниться локально на вашем устройстве.

## Технологический стек
- Java
- Gradle
- Android SDK
- SQLite
