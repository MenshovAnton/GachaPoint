**GachaPoint** — это приложение-компаньон для гача-игр (таких, как *Genshin Impact* и *Honkai: Star Rail*), предназначенное для удобного и безопасного отслеживания истории круток, накоплений и прогресса сбора наград с подписок (пример: Луна, Интернот-подписка) прямо на вашем устройстве.

## Возможности и фишки
- **Отслеживание подписок** - наглядная статистика по вашим подписками в виде календаря и счетчика гемов/круток
- **История круток** - сохраняйте историю ваших круток, следите за вашим прогрессом*
- **Менеджер накоплений** - следите за прогрессом ваших накоплений.
- **Ежедневные напоминания** - напомнит забрать награды в игре.
- **Автономная работа** - вся информация храниться локально на вашем устройстве.
- **Нативный UI** - работает на чистом Jetpack compose, не зависит от веб-страниц.

## Технологический стек
- Java
- Gradle
- Android SDK
- Room Database
- Jetpack Compose
